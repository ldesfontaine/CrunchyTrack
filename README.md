# CrunchyTrack

> [!NOTE]
> Projet personnel réalisé à deux en 2023. Le dépôt est conservé comme souvenir
> de nos premiers projets et n’est plus maintenu.

CrunchyTrack est une extension Chrome Manifest V3 conçue pour suivre
l’historique de visionnage d’un utilisateur sur Crunchyroll.

Le projet comprend l’extension, son interface et la logique de collecte. Le
stockage distant expérimental se trouve dans le dépôt associé
[CrunchyTrackApi](https://github.com/ldesfontaine/CrunchyTrackApi).
